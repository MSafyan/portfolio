Summary
Next.js/Vercel Developer for Affiliate Website + API Integration

We’re building a standalone website (Next.js on Vercel) that will serve as a lifestyle hub. The site will showcase curated travel/tour experiences, integrate affiliate tracking, and connect into an existing mobile app through APIs.

We already have a full technical specification, schema, and starter codebase (Next.js + Prisma + API routes scaffold). Your role is to take this starter, implement the features, and deploy production-ready on Vercel.


Core Deliverables
• Finish build of the site on Next.js (App Router) with Vercel Functions.
• Implement Prisma/Postgres schema for Providers, Tours, Clicks, and Conversions.
• Build secure Provider Portal with authentication (Clerk or Supabase) where operators can:
– Create/update profile (company info, affiliate details, payout terms).
– Upload/edit tour listings (strict image requirements, descriptions, URLs, media).
– Upload CSV booking reports OR set up webhook endpoints.
• Implement click tracking & redirect flow:
– User must be logged in before outbound click.
– Log click → redirect to affiliate URL with UTM.
• Implement webhook endpoint for real-time booking confirmations with HMAC verification.
• Build Admin Dashboard for reporting: clicks, conversions, commissions, CSV/XLSX export.
• Integrate reward bridge: on booking confirmation, call external API to award XP/badges/perks.
• Enforce media upload validation (dimensions, formats, size).
• Secure APIs with JWT, HMAC, and CORS allowlists.

• Next.js 14+ on Vercel (App Router)

• File storage (Supabase Storage or S3 compatible)
