Job Description

We’re building a capital-raising / investor readiness marketplace platform; a dashboard where businesses can onboard, get verified, upload docs, get a valuation & cap table, connect with investors via scheduled calls, receive notifications & messaging.

I’m looking for a senior full-stack engineer or small team who can build this end-to-end, from onboarding, backend + frontend, infra, integrations, to launch.

What You’ll Be Responsible For

1. Building a Fastify backend (API server)
2. Building a Next.js frontend (dashboard, UI)
3. Integrating Persona for identity verification / KYC
4. Integrating Plaid (or bank linking) if needed for financials / bank statements
5. Integrating Carta (or an equivalent) for cap table management and 409A valuations
6. Building an internal data-room module: allow users to upload resources / documents (financials, pitch deck, legal docs etc.), manage access
7. Authentication & user roles (founder, admin, investor, account manager)
8. Scheduling module: use Cal.com (or similar) for booking discovery / investor calls
9. Notifications & in-app messaging: integrate Knock for notifications + Ably for real-time chat
10. External communication: email (SendGrid), SMS / voice (Twilio)
11. Infrastructure & hosting: on Google Cloud Platform (GCP), setup CI/CD, repos (backend, frontend, infra). Should handle scaling, security, backups etc.

Research & propose any additional services/technologies/tools needed to fill gaps (security, payments / escrow, document signing, audit, legal compliance etc.)

Required Skills / Qualifications

Strong experience building full-stack web applications, especially with Next.js (React) and Fastify (or similar high-performance Node.js frameworks)

Experience integrating third-party APIs and services (especially Persona, Plaid, Carta or equivalent).

Solid understanding of authentication, permissions, security, and compliance.

Experience building document upload / data room functionality with proper security / encryption.

Real-time messaging / notifications integration (Ably / Knock or similar).

Experience with calendaring/scheduling tools (e.g. Cal.com) and external comms (Twilio, SendGrid).

Experience setting up infrastructure in GCP, CI/CD pipelines, git repo management.

Good understanding of startup / SaaS product thinking: user flows, edge cases, error handling etc.

Nice-to-Haves

Experience with equity, cap tables, 409A valuations, or companies like Carta

Familiarity with legal/financial compliance for fundraising or capital markets

Experience building marketplace or investor-facing dashboards

UX/UI skills or working closely with UI/UX designers
