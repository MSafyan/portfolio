# Projects Quick Reference Guide

## When to Use Each Project in Proposals

### AI/LLM & Vector Databases
**Use Abundance Movement when job involves:**
- RAG (Retrieval-Augmented Generation) systems
- Vector databases (Pinecone, pgvector, Weaviate)
- OpenAI embeddings and semantic search
- LLM cost optimization
- Chat summarization or content analysis
- Multi-namespace/multi-tenant AI systems

**Key metrics:** 95% cost reduction, 200k+ documents, semantic matching

---

### Data Pipelines & ETL
**Use Palmetto Air Balance when job involves:**
- Azure Data Factory or data pipelines
- ETL (Extract, Transform, Load) workflows
- Incremental loads with watermarks
- Dimensional modeling (star schema)
- Enterprise data warehouse design
- Business intelligence dashboards (Power BI)
- NetSuite or ERP integrations

**Key metrics:** 50+ pipelines, 2M+ records daily, 99.9% reliability

---

**Use Pink Chicken when job involves:**
- Multi-source data integration (10+ sources)
- E-commerce platforms (Shopify)
- WMS (Warehouse Management Systems)
- Retail-specific data modeling
- Inventory management across locations

**Key metrics:** 10+ stores unified, virtual warehouse logic

## Project Selection Tips

1. **Match the domain first:** E-commerce → FashionXotics/P2G, Healthcare → (none yet), Finance → (none yet)
2. **Match the tech stack second:** AWS → Helpicon, Azure → Palmetto, AI/LLM → Abundance
3. **Match the metrics third:** High volume? → Palmetto (2M+ records), Cost savings? → Abundance (99.9% reduction)
4. **Use 1-2 projects max per proposal:** Primary project + supporting example
5. **Name the project clearly:** "At Abundance Movement, I built..." not "In a previous project..."
