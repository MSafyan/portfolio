# Database Warehouse Engineering Project
## Enterprise Data Platform Implementation for Palmetto Air Balance

### Executive Summary
Led the design and implementation of a comprehensive enterprise data warehouse solution integrating multiple business systems (NetSuite, Air1, UKG) to provide real-time business intelligence and operational dashboards. The solution processes complex project management data, financial metrics, and operational KPIs to enable data-driven decision making across the organization.

---

## Technical Architecture

### **Cloud Infrastructure (Azure)**
- **Azure SQL Database**: Primary data warehouse using Azure SQL Database with automated scaling
- **Azure Data Factory (ADF)**: ETL/ELT pipeline orchestration with 20+ data pipelines
- **Azure Storage**: Blob and file storage for data lake architecture
- **Private Endpoints**: Secure network architecture with private DNS zones

### **Data Pipeline Architecture**
```
Source Systems → ETL/ELT Processing → Azure SQL Warehouse → Power BI
     ↓                    ↓                    ↓              ↓
- NetSuite      - Databricks          - Data Models    - Dashboards
- Air1          - ADF Pipelines       - Fact Tables    - KPI Reports
- UKG           - Stored Procedures   - Dimensions     - Analytics
                - Error Handling      - Views          - Alerts
```

## Complex Business Logic Implementation

### **Backlog Calculation Engine**
```sql
-- Simplified representation of backlog calculation logic
SELECT 
    project_id,
    contract_price + COALESCE(change_orders, 0) - COALESCE(invoiced_amount, 0) as backlog_amount,
    GETDATE() as snapshot_date
FROM project_management pm
LEFT JOIN change_orders co ON pm.project_id = co.project_id
LEFT JOIN invoices i ON pm.project_id = i.project_id
WHERE pm.project_status = 'Active'
```
